DejaVu Sans e DejaVu Sans Bold, sem modificações, da distribuição oficial [DejaVu Fonts 2.37](https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37).

A [licença oficial](https://dejavu-fonts.github.io/License.html) acompanha os arquivos em `LICENSE`. As fontes são incorporadas aos PDFs para preservar acentos, caracteres gregos e símbolos matemáticos suportados sem depender das fontes do servidor. Caracteres sem glifo disponível geram erro de validação, em vez de sair como quadrados no documento.
